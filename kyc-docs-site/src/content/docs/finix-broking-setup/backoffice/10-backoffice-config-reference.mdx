> **Why this page exists:** The back office is where regulatory deadlines turn into configured values — a retention period, a contract-note window, a payment window, a reporting cut-off. Several of them are statutory caps or floors with no discretion, and mixing those with the firm's own choices in one undifferentiated settings file is how a floor gets treated as a preference. This page separates them.

## TL;DR

- **Four values in this plane are statutory and absolute**: the eight-year retention floor, the 24-hour contract-note window, the five-trading-day <abbr title="Client Unpaid Securities Pledgee Account.">CUSPA</abbr> cap, and the prohibition on cash.
- **Three gates block the pipeline by design**: current-day masters, reconciled trades before contract notes, and a closed ledger before statements. Each is a deliberate refusal to proceed on bad inputs.
- **Deadlines are configured as internal targets, not external limits.** The runbook works to the internal number; the external one is recorded for reference.
- **Batch idempotency is configuration, not a hope.** Operators re-run under pressure, and a non-idempotent re-run converts a delay into a corruption.
- **The two directions of the CUSPA treatment must both be right**: excluded from risk capacity, included in margin collection reporting where it legitimately counts.

## 1. Classification

**R** regulatory · **E** exchange, clearing corporation or depository set · **D** discretionary. The *Blocks* column names what the firm refuses to do when the value's condition is not met.

## 11. The absolute values

<Aside type="caution" title="No discretion below or beyond these">
**`finix.cmp.retention.books_years` = 8** — a floor, not a target. **`finix.bo.cn.deadline_hours` = 24** from execution — a ceiling. **`finix.bo.cuspa.payment_window_days` = 5 trading days** — a cap; a shorter firm policy is permitted, a longer one is a breach. **`finix.cmp.complaint.clock_days` = 21 calendar days** — a ceiling, and calendar days. **`finix.bo.ledger.cash_head` = absent** — a prohibition, not a limit. Each of these appears in a regulation or circular with no discretion attached, and treating any of them as a tunable is the error this table exists to prevent.
</Aside>

## 12. The pipeline gates

| Gate | Condition | Blocks |
|---|---|---|
| Masters current | `master.assert_current_day` | All processing |
| Trades reconciled | `recon.block_contract_notes_on_diff` | Contract notes, and therefore the 24-hour clock |
| Ledger closed | `stmt.requires_ledger_close` | Statements |
| Obligations tied out | `settle.obligation_tie_out_required` | Settlement preparation |
| Source data closed | `rpt.requires_source_close` | Report extraction |
| Validation passed | `rpt.validation_mandatory` | Submission |
| Trades allocated | `trade.unallocated_action` | Everything downstream |
| CUSPA pledge created | `cuspa.autopledge_at_payout` | Further exposure for that client |
| Balance extract to risk | `finix.bo.extract.rms_blocking` | **Next day's open** |
