> **Why this page is structured this way:** An inspection does not ask whether the firm is compliant; it asks what the control is, where it sits, what evidences its operation and who owns it. That is a four-column table, and a firm that has it answers in minutes while a firm that does not spends a fortnight assembling it from code and recollection. So this page is that table, preceded by the classification rules that make it meaningful and followed by the registers and assertions that keep it honest.

## TL;DR

- **Four columns answer almost every inspection question**: obligation, configuration that implements it, system that evidences it, person who owns it.
- **Classification is the part that is easiest to get wrong and fastest to be noticed.** Regulatory values need a circular; exchange-set values need an ingestion job with a staleness behaviour; discretionary values need an approved policy and an approver.
- **Five values are statutory absolutes** with no discretion: the eight-year retention floor, the 24-hour contract-note window, the five-trading-day <abbr title="Client Unpaid Securities Pledgee Account.">CUSPA</abbr> cap, the 21-calendar-day complaint clock, and the prohibition on cash from clients.
- **Seven values must mirror the client-facing risk management policy** exactly, because operating outside a disclosed mandate is the finding an arbitrator reaches first.
- **Eleven registers carry the evidence**, and each has an owner and a retention period.
- **The daily assertions are the heartbeat**: segregation, upstreaming computed versus confirmed, the begin-of-day gates and the extract that unblocks tomorrow.
- **An obligation without an owner should alarm.** It is the single most valuable control on this page.

## 1. Classification rules

| Class | Evidence required | What must also exist |
|---|---|---|
| **Regulatory** | The regulation or circular, with paragraph | Implementation evidence; change control through compliance |
| **Exchange-set** | The circular, **plus a named ingestion job** | A staleness threshold and a stated behaviour on staleness |
| **Discretionary** | A board or committee-approved policy, with an approver and a date | Client disclosure where client-affecting |

| Common misclassification | Reality |
|---|---|
| "<abbr title="Securities and Exchange Board of India">SEBI</abbr> allows 5x leverage" | The **multiplier is discretionary**, bounded by margin rules |
| "We keep records for seven years" | **Eight years is a statutory floor** under regulation 16 |
| "Complaint resolution in 21 working days" | **21 calendar days** under regulation 10(e) |
| "We allow 50 percent cash because SEBI requires it" | The cash-equivalent minimum binds the **clearing member**, not each client |
| "The exchange sets our square-off trigger" | **Discretionary and disclosed** |
| "Cash is discouraged" | **Prohibited** by regulation 20(d) |
| "Our unpaid-securities window is our policy" | **Capped at five trading days**; shorter is permitted, longer is a breach |

<Aside type="caution" title="Misclassification is visible immediately">
An inspector asking "under what authority do you apply this limit" and receiving a circular reference for a discretionary value, or a policy document for a statutory one, learns something about the firm's understanding in one question. The classification column is therefore not administrative tidiness — it is a direct demonstration of whether the firm knows which of its rules are its own. Review it with the same seriousness as the values themselves.
</Aside>

## 3. The statutory absolutes

No discretion in either direction.

| Value | Rule |
|---|---|
| `finix.cmp.retention.books_years` | **8** — a floor, not a target |
| `finix.bo.cn.deadline_hours` | **24 from execution** — a ceiling |
| `finix.bo.cuspa.payment_window_days` | **5 trading days** — a cap; shorter is permitted |
| `finix.cmp.complaint.clock_days` / `clock_basis` | **21 / calendar** — a ceiling, in calendar days |
| `finix.bo.ledger.cash_head` | **Absent** — a prohibition |

## 4. The policy-mirror set

These configuration values appear verbatim in the client-facing risk management policy. **Changing one without updating the other puts the firm outside its disclosed mandate.**

| Value | Policy statement it mirrors |
|---|---|
| `finix.rms.squareoff.warn_pct` | When the client is warned |
| `finix.rms.squareoff.trigger_pct` | When the firm acts |
| `finix.rms.squareoff.grace_minutes` | How long the client has |
| `finix.rms.squareoff.selection_rule` | Which positions are closed first |
| `finix.rms.squareoff.intraday_time` | When intraday positions are closed |
| `finix.rms.limits.exposure_multiplier` | The leverage offered |
| `finix.rms.collateral.client_cash_policy` | Any client-level cash requirement, **as the firm's own policy** |

| Control | Detail |
|---|---|
| Change request | For any of these keys, requires the policy version that will accompany it |
| Deployment gate | The change does not deploy without the policy update |
| Review | Quarterly, in the risk committee, against the published policy |
| Client communication | Where capacity reduces |

## 8. Exception paths

| Situation | Response |
|---|---|
| A deployed value differs from the approved register | Investigate the change path; revert or approve; this is a control failure |
| A policy-mirror value changed without the policy | **Revert immediately**; the firm is operating outside its disclosed mandate |
| A statutory absolute found outside its bound | Severity one; correct; assess the period affected and the disclosure obligation |
| An obligation is found with no owner | Assign; investigate how it was created unowned |
| A register is incomplete | Reconstruct; a register with gaps is weak evidence |
| A circular changes a configured value | Assess, implement, update the register and the manual's figure |
| Evidence cannot be produced for a past period | **High severity**; this is what retention and registers exist for |
| An inspection asks a question the map does not answer | Add the row; the map is a living artefact |

## Practical notes

- **Build the map as the stack is built.** Retro-fitting it is archaeology.
- **Review the classification column as carefully as the values.** It demonstrates whether the firm knows which rules are its own.
- **Gate the policy-mirror keys on a policy version.** It is the cheapest protection against the finding an arbitrator reaches first.
- **Alarm on unowned obligations.** One rule, one failure class prevented.
- **Keep the filing register on acknowledgements, not submissions.** Non-submission is treated far more harshly than late submission.
- **Diff deployed configuration against the approved register monthly.** Drift is silent and cumulative.
- **Treat the daily segregation assertion as the heartbeat.** It is the firm's central claim about client money.
