## Not finding your role?

The 12 above cover the most common readers but they overlap. Two heuristics if you're between two roles:

- **You build software** → start with **Backend Engineer** or **Frontend / UX Engineer**.
- **You sign things that the regulator might inspect** → start with **Compliance Officer**.
- **You sign things that affect the firm's capital** → start with **Finance / CFO**.
- **You explain the firm's broker-ops to someone outside the firm** → start with **Operations Lead**.

You can also skip the persona layer entirely and use the sidebar — that's how the site was organized before this layer was added. It still works.
